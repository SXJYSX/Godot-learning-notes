行为模式类节点 需要 最终通知到StateMachine就可以了，或者能令StateMachine 获取数据就行了。

数据 —— 类似于用户输入，这一帧：摇杆(1,0)，按下了跳跃键，输入了某些指令（比如多个字符串）

### 问题 1：动作 State 如何“向上告知”与“告知外界”？

在这种三分立架构中，“向上”和“向外”的职责分工极其明确：

#### 1. 向上告知 `StateMachine` 切换状态：通过【带优先级的信号】

`State` 不直接修改 `StateMachine` 的变量，而是向外抛出带参信号，由 `StateMachine` 收集并统筹：

```GDScript
# State.gd (动作状态基类)
class_name State extends Node

# 信号参数：1. 目标状态名  2. 该切换请求的优先级 (数值越大越优先)
signal transition_requested(target_state_name: String, priority: int)

var actor: CharacterBody2D
var brain: CharacterBrain
```

#### 2. 告知外界“这一帧向右移动 + 跳跃”：通过【直接修改 Actor 属性与驱动组件】

“外界”主要指：**物理系统（速度）、视觉系统（转向与动画）**。`State` 每帧读取 `Brain` 的变量，并直接作用于它们：

```GDScript
# MoveState.gd 或 JumpState.gd
func physics_update(delta: float) -> void:
	# 1. 告知物理系统：读取 Brain 的 X 轴移动意图，填入物理速度
	actor.velocity.x = brain.move_dir.x * SPEED
	
	# 2. 告知物理系统：如果 Brain 有跳跃意图，给 Y 轴瞬间初速度
	if brain.consume_jump_request():
		actor.velocity.y = -JUMP_VELOCITY
	
	# 3. 告知视觉系统：控制转向与播放动画
	if brain.move_dir.x != 0:
		actor.pivot.scale.x = sign(brain.move_dir.x)
	
	actor.animation_player.play("run")
```
