
请示范在 Godot 4 中如何配置 PointLight2D 与 Light Mask 来实现角色在暗处的剪影与局部光照效果。

Godot 4 实现暗处剪影与局部光照的核心，在于全局环境压暗（`CanvasModulate`）**与**光照掩码（`Light Mask` 与 `Item Cull Mask`）的互相配合。

### 🛠️ 具体配置步骤

#### 1. 全局环境压暗（压出“剪影”效果）

1. 在主关卡场景（Level）根节点下添加一个 **`CanvasModulate`** 节点。
    
2. 在 Inspector 中选中它，将 **`Color`** 调成深蓝色或近黑色（例如 `#0c0d14`）。
    
3. **效果**：全场所有未受光的 Sprite 瞬间变成黑色剪影。
    

#### 2. 配置图层掩码（Light Mask）

为了实现“玩家在暗处有微弱自发光（不至于完全找不到人），但火把又能把玩家彻底照亮”的效果，我们需要规划光照掩码：

- **Layer 1**：环境地图（TileMap / 墙壁）
    
- **Layer 2**：玩家本体（Player Sprite）
    

修改节点属性：

- 选中 **`Player/Pivot/AnimatedSprite2D`**：
    
    - 打开 `CanvasItem` → `Visibility` → **`Light Mask`**。
        
    - 勾选 **Layer 1** 和 **Layer 2**（使其能同时接收环境光和角色专属光）。
        
- 选中关卡中的 **`TileMapLayer`**（环境墙壁）：
    
    - **`Light Mask`** 只勾选 **Layer 1**。
        

#### 3. 配置玩家微弱自发光（PointLight2D）

在 `Player/Effects` 下创建一个 `PointLight2D`（命名为 `AmbientLight`）：

1. **`Texture`**：新建一个 `GradientTexture2D`（设置为 Fill: Radial 径向渐变，中心白、边缘透明黑）。
    
2. **`Energy`**：设为 `0.3`（弱光，仅用于在全黑处勾勒角色体态）。
    
3. **`Range` → `Item Cull Mask`**：**只勾选 Layer 2**。
    
    - _关键点_：这束弱光**只会照亮 Player 自己**，玩家走过墙壁时不会把墙壁拉亮，确保剪影感不破坏。
        

#### 4. 配置场景火把/局部光源（PointLight2D）

在关卡墙壁上挂一个 `PointLight2D`（如火把或水晶）：

1. **`Texture`**：分配同样的径向渐变光照纹理。
    
2. **`Energy`**：设为 `1.5`（强光）。
    
3. **`Range` → `Item Cull Mask`**：**同时勾选 Layer 1 和 Layer 2**。
    
    - _效果_：平时墙壁和玩家都是黑的；当玩家走到火把附近时，玩家从剪影状态被暖色调火把彻底照亮，同时墙壁也被照亮。
        

### 📊 光照掩码配置速查表

|节点类型|节点路径|光照/掩码属性设置|最终视觉效果|
|---|---|---|---|
|**`CanvasModulate`**|`Level/CanvasModulate`|`Color = #0c0d14`|全场压暗，提供黑夜底色|
|**`TileMapLayer`**|`Level/TileMap`|`Light Mask = 1`|没灯照射时呈现纯黑墙壁|
|**`AnimatedSprite2D`**|`Player/Pivot/Sprite`|`Light Mask = 1, 2`|暗处为剪影，能被所有灯照亮|
|**`PointLight2D`** (玩家自发光)|`Player/Effects/AmbientLight`|`Item Cull Mask = 2`, `Energy = 0.3`|**只亮自己**，在全黑中保持轮廓可见|
|**`PointLight2D`** (场景火把)|`Level/Torch`|`Item Cull Mask = 1, 2`, `Energy = 1.5`|**同时照亮玩家与墙壁**，产生高亮对比|

你的总结非常切中要害！绝大多数 2D 平台游戏（包括《空洞骑士》《TEVI》《蔚蓝》）90% 的场景都是**常规全局明亮状态**，根本不需要给每一个场景和节点都去配置复杂的 Light Mask。

在实际商业开发中，光照系统是作为“可插拔的局部环境组件”来处理的，不需要为了少数暗部关卡去重构整个游戏的节点树。

**1. 常规关卡（白昼/户外/标准室内）：零额外开销**

- **配置方式**：关卡中**不添加** `CanvasModulate`（或将颜色保持为默认纯白 `#ffffff`）。
    
- **渲染机制**：Godot 2D 引擎默认以标准纯白光照渲染所有物体。Sprite 无需做任何掩码计算，性能开销最小。
    

**2. 少数黑暗关卡（山洞/深夜/地牢）：按需压暗**

- **配置方式**：只在**这个特定关卡**的节点树根部拖入一个 `CanvasModulate` 节点，将 Color 调暗（如 `#121220`）。
    
- **渲染机制**：这一行节点瞬间将该关卡内所有默认图层的物体全部压暗，而不需要你去修改玩家或地块的代码。
    

**3. 玩家节点树如何自适应（无需切换架构）**

为了让玩家节点在“明亮关卡”和“黑暗关卡”之间无缝切换，你甚至**不需要编写控制灯光开关的代码**：

- **微弱自发光（`AmbientLight`）**：保持其开启，`Energy` 设为较低值（如 `0.2~0.3`）。
    
    - 在**明亮关卡**中：环境本身就是亮的，`0.3` 亮度的灯光叠加在纯白贴图上**完全不可见**，不会破坏画面。
        
    - 在**黑暗关卡**中：环境被 `CanvasModulate` 压暗后，这 `0.3` 的亮度会自然凸显出来，形成轮廓自发光。
        
- **手提灯/特殊光源（如提灯）**：如果只有某些暗部关卡才允许玩家挂载手提灯，可以在该关卡入口通过 `Area2D` 或关卡加载脚本，单行代码控制 `HandLight.enabled = true / false`。
    

**总结**：你的节点树架构依然保持最优雅的全局通用性。平常开发时完全不用理会光照；只有遇到“黑夜/山洞”场景时，给该场景丢一个 `CanvasModulate`，整个光照机制就会自动生效。

CanvasModulate 是什么？

**CanvasModulate** 是 Godot 中用于 **2D 全局调色与环境压暗** 的节点。

它的核心原理是**颜色乘法（Color Multiplication）**：它会将其设置的 `color` 属性与整个 2D 画布（或所在的 CanvasLayer）上所有物体的颜色相乘。

### 💡 核心作用与使用场景

- **黑夜与山洞环境（最常用）**：
    
    - **默认状态 (`#ffffff`)**：颜色与 1.0 相乘，保持原始色彩与明亮度。
        
    - **暗夜/地牢状态 (`#1a1d2e`)**：颜色与深蓝/黑色相乘，全场瞬间变暗，形成黑夜或暗室的效果。
        
- **昼夜交替系统（Day-Night Cycle）**： 通过平滑修改 `CanvasModulate` 的 `color` 属性，可以轻松实现清晨（橙黄）→ 正午（纯白）→ 黄昏（紫红）→ 深夜（深蓝）的全局光照渐变。
    
- **全屏色彩氛围与滤镜**： 如中毒时的全屏绿调、被击中时的全屏一闪而过的红调、或复古滤镜。
    

### 🛠️ 与 2D 灯光（PointLight2D）的配合逻辑

在 Godot 的 2D 光照工作流中，`CanvasModulate` 充当的是“画板底层”的角色：

1. **先压暗（全局）**：加入 `CanvasModulate` 并把颜色调成深色，把原本明亮的场景强行变为黑夜。
    
2. **再抠亮（局部）**：在玩家身上、火把或水晶旁挂载 `PointLight2D`，把被压暗的区域重新“擦亮”。
    

### 📝 代码控制示例

在 GDScript 中，你可以用 `Tween` 动画非常平滑地控制环境光压暗：

GDScript

```
# 3 秒内将全局环境平滑过渡到深蓝色（模拟进入暗室）
func enter_dark_cave() -> void:
    var tween = create_tween()
    tween.tween_property($CanvasModulate, "color", Color("101428"), 3.0)
```

### 1. 节点搭建：直接将光源挂在子弹/特效节点下

最干净优雅的做法，是**把 `PointLight2D` 直接作为子弹（Bullet）或蓄力特效节点的子节点**。子弹飞到哪，光就跟到哪；子弹销毁，光自动消失。

Plaintext

```
ChargeEffect / Bullet (Node2D 或 Area2D/Hitbox)
├── AnimatedSprite2D             ← 子弹/蓄力贴图
├── CollisionShape2D
└── MagicLight (PointLight2D)    ← 随子弹移动的动态光源
```

### 2. 调出“自然不刺眼”光照的 3 个关键设置

如果在白天的明亮场景下直接用默认纯白大灯泡，画面会瞬间过曝（变成一片死白）。要实现《Rabi-Ribi》那种柔和自然的效果，关键在于以下三点：

#### ① 使用超柔和的渐变纹理（Soft Radial Gradient）

- 为 `PointLight2D` 的 `Texture` 赋予一张 **径向渐变图（`GradientTexture2D`）**。
    
- **非常关键**：渐变必须是中心亮、**边缘极其平滑过渡到完全透明**的羽化效果（Alpha 降为 0）。绝不能有明显的圆环边界，这样照在场景和角色身上才会有柔和的“光晕感”。
    

#### ② 永远使用“带颜色的光”，不要用纯白光（Colored Light）

- **原理**：纯白光叠加在原本就明亮的地块/角色贴图上，会导致 RGB 通道瞬间溢出变成 `#FFFFFF`（死白）。
    
- **做法**：如果 Ribbon 射出的是粉色魔法弹，就把 `PointLight2D` 的 `Color` 调成**粉彩色/马卡龙粉（如低饱和度的粉色或浅蓝色）**，`Energy` 设为较低的 `0.3 ~ 0.6`。
    
- **效果**：彩色低能量光叠加在明亮场景上，**只会产生“提亮 + 提色（Tint）”的效果**，让周围环境染上一层魔法光辉，而不会过曝。
    

#### ③ 开启 2D Glow（辉光）提升质感（WorldEnvironment）

《Rabi-Ribi》子弹那种“通透发光”的核心秘密，其实很大一部分来自于**辉光（Glow）**：

1. 在场景中添加一个 **`WorldEnvironment`** 节点。
    
2. 开启 `Environment` → **`Glow`**（勾选 `Enabled`，模式设为 `Canvas`）。
    
3. 将子弹 `AnimatedSprite2D` 的 `Self Modulate` 或颜色调为 **HDR 超亮颜色**（例如 RGB 值设为 `1.5` 或 `2.0`）。
    
4. **效果**：子弹本体自己会泛出好看的霓虹光晕（Glow），而底下的 `PointLight2D` 负责把这层光轻轻扫到周围的地块和角色身上。
    

### 3. 代码进阶：实现“蓄力时光源逐渐变大”的动态效果

在 Ribbon 蓄力时，你可以用代码让这个 `PointLight2D` 的范围和亮度随蓄力进度逐渐变大，形成极佳的视觉反馈：

GDScript

```
# RibbonChargeEffect.gd (挂载在蓄力动画/子弹上)
extends Node2D

@onready var magic_light: PointLight2D = $MagicLight

# 模拟蓄力进度 (0.0 到 1.0)
func update_charge_light(charge_ratio: float) -> void:
	# 随蓄力进度，灯光范围从 0.5 倍放大到 1.5 倍
	magic_light.texture_scale = lerp(0.5, 1.5, charge_ratio)
	# 亮度从微弱的 0.2 提升到 0.8
	magic_light.energy = lerp(0.2, 0.8, charge_ratio)
```

这种处理方式下，无论游戏场景是黑夜还是白昼，子弹和蓄力特效都能呈现出极其自然且带有打击感的魔法光效。
