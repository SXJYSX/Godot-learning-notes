如何控制开关某些传感器？总有些行为逻辑 不需要全体传感器都打开，这样可以节省性能。

---
对，`Sensors` 节点只需要作为一个**分类文件夹（纯 Node）**，方便在编辑器里组织节点。大脑 `XXBrain` 通过 `@export` 显式拉取需要用的传感器即可。

### 一、 如何按需开关传感器（性能优化）

Godot 针对不同类型的传感器，提供了不同维度的开关方式。推荐在 `Brain` 中根据当前的 AI 模式（如从“巡逻”切到“追击”）批量切换：

#### 1. 常见传感器的精准底层开关

- **`RayCast2D` (射线)**：`ray_cast.enabled = false`（直接停止物理检测）。
    
- **`Area2D` (视野/近身圈)**：`area.monitoring = false`（停止重叠检测，耗能最高，强烈建议不切追击时关闭大范围视野）。
    
- **自定义组件/普通 Node**：`component.set_physics_process(false)`。
    

#### 2. 在 Brain 中优雅控制开关

在 `Brain` 中写一个专门控制开关的私有函数，当 AI 模式改变时调用一次即可，绝不浪费一丁点 点 CPU：

```GDScript
# GoblinBrain.gd
@export var sight_area: Area2D      # 远距离视野（耗能大）
@export var wall_raycast: RayCast2D  # 防撞墙射线

func _on_ai_mode_changed(new_mode: AIMode) -> void:
	match new_mode:
		AIMode.PATROL:
			sight_area.monitoring = true    # 巡逻时：开启视野找玩家
			wall_raycast.enabled = true     # 巡逻时：开启射线防撞墙
			
		AIMode.CHASE:
			sight_area.monitoring = false   # 追击时：已经锁定玩家，关闭大范围视野节省性能！
			wall_raycast.enabled = false    # 追击时：依赖寻路组件，关闭普通撞墙射线
```
