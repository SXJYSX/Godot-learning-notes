## **1. 画面显隐（UI 面板最常用）**

- **激活**：`node.show()` 或 `node.visible = true`
    
- **失活**：`node.hide()` 或 `node.visible = false`
    

## **2. 逻辑与输入响应（Process/Input）**

### **2.1：会自动对所有子节点生效! 因为 节点的Process属性的Mode 默认都是Inherit
- **激活**：`node.process_mode = PROCESS_MODE_INHERIT`
- **失活**：`node.process_mode = PROCESS_MODE_DISABLED`
##### *如果想要某个节点 始终有逻辑与输入响应，就得把 **Mode** 设置为 **Always***

### `process_mode = PROCESS_MODE_DISABLED` 到底干了什么？

当一个 Godot 节点的 `process_mode` 设置为 `DISABLED` 时，引擎会彻底**切断该节点及其所有 `INHERIT` 子节点的逻辑生命周期**：

1. **停止代码帧轮询**：不再执行 `_process(delta)` 和 `_physics_process(delta)`。
    
2. **切断事件输入**：不再响应 `_input(event)`、`_unhandled_input(event)` 以及 UI 鼠标点击事件。
    
3. **冻结物理与碰撞**：`CharacterBody2D` 停止移动，`Area2D` 停止侦测重叠，`CollisionShape2D` 不再参与物理碰撞。
    
4. **【关键差异】保留静态渲染**：**它不会自动隐藏画面！** 如果这个节点是一个带有纹理的 `Sprite2D`，虽然它不再移动或响应输入，但图像依然会留在屏幕上。必须搭配 `hide()` 才能达到物理与画面的双重隐形。

set_process(false)
