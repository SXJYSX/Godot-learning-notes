“向上通知，向下调用”（Godot 社区常说的 **“Signal Up, Call Down”**）是 Godot 节点解耦与架构设计中最核心的黄金法则。

它的底层逻辑非常简单：**父节点知道子节点的存在，所以可以直接指挥子节点；子节点不应该知道父节点是谁，所以发生事情时只管发信号“喊一声”，由父节点决定怎么处理。**

### 为什么必须“向上通知”？（反面教材）

假设你写了一个受击盒 `Hurtbox.gd`，如果不用向上通知，而是直接“向上调用”：

GDScript

```
# ❌ 坏代码：子节点强行向上调用父节点
# Hurtbox.gd
func take_damage(damage: int) -> void:
    # 直接拿到父节点 Player 并修改属性
    get_parent().hp -= damage
    get_parent().play_hurt_animation()
```

**这种写法会导致两个严重后果：**

1. **彻底失去复用性**：如果这个 `Hurtbox` 挂到“木箱（Crate）”或者“怪物（Enemy）”身上，因为木箱没有 `hp` 或 `play_hurt_animation()` 方法，游戏会直接**崩溃报错**。
    
2. **极易引发空指针/空节点 Bug**：只要你在场景树里调整了一下节点层级，`get_parent()` 就会指向错误的节点。
    

### “向上通知”的具体实现步骤（GDScript 4.0）

“向上通知”在 Godot 中就是**定义并抛出自定义信号（Signal）**。分为标准四步：

#### 1. 在子节点中：声明信号 (`signal`)

在子节点脚本顶部，定义一个属于该子节点的通知：

GDScript

```
# Hurtbox.gd (子节点)
class_name Hurtbox
extends Area2D

# 1. 声明信号（可以带参数，也可以不带）
signal hit_received(damage: int, attacker_pos: Vector2)
```

#### 2. 在子节点中：触发并发射信号 (`emit`)

当事件发生时，子节点只管广播这个通知，**完全不管谁在听**：

GDScript

```
# Hurtbox.gd (子节点)
func receive_damage(damage: int, attacker_pos: Vector2) -> void:
    # 2. 向上广播：我受击了！把数据抛出去！
    hit_received.emit(damage, attacker_pos)
```

#### 3. 在父节点中：连接信号 (`connect`)

父节点在 `_ready()` 中绑定监听（或者在编辑器面板的“节点-信号”标签页里用鼠标连接）：

GDScript

```
# Player.gd (父节点)
extends CharacterBody2D

@onready var hurtbox: Hurtbox = $Pivot/Hurtbox

func _ready() -> void:
    # 3. 父节点主动监听子节点的通知
    hurtbox.hit_received.connect(_on_hurtbox_hit_received)
```

#### 4. 在父节点中：编写响应逻辑

父节点收到通知后，自己决定怎么做：

GDScript

```
# Player.gd (父节点)
# 4. 收到通知后的回调函数
func _on_hurtbox_hit_received(damage: int, attacker_pos: Vector2) -> void:
    if is_invincible:
        return
        
    hp -= damage
    play_hurt_animation()
```

### 总结与对比

|**维度**|**向下调用 (Call Down)**|**向上通知 (Signal Up)**|
|---|---|---|
|**方向**|父节点 $\rightarrow$ 子节点|子节点 $\rightarrow$ 父节点|
|**手段**|`$Pivot/Sprite.play("run")` 或 `$Timer.start()`|`my_signal.emit()`|
|**依赖关系**|父节点依赖子节点的接口（合情合理）|子节点**零依赖**父节点（高度解耦）|
|**好处**|操控直接，代码顺畅|子节点变成“独立模块”，放到哪都能用|

遵循这套规则后，你的 `Hurtbox` 挂在玩家身上，玩家监听它并扣血；挂在木箱身上，木箱监听它并播放碎裂粒子；挂在 Boss 身上，Boss 监听它并切换锁血形态。`Hurtbox` 本身的代码一行都不需要改！
