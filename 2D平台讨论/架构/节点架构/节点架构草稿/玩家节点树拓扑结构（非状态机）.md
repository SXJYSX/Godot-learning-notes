Q.
我发现这些游戏中（依然是Rabiribi，TEVI，空洞骑士这类游戏），有的场景有玩家水面上的倒影；有的场景很黑，角色就像一个剪影，但微弱的光源能照亮玩家的一部分、照亮场景的一部分。

有的时候为了游戏逻辑通常，角色需要有额外的 自定义的 射线检测。

Rabiribi中的Erina起跳时 脚下会生成一些亮亮的小粒子。

实现这些内容 是否需要修改 玩家节点树拓扑结构？

A.
**不需要推翻原有结构，只需进行平滑扩展。** 原有的“物理在根、方向敏感在内”的架构完全没变，新加的特性只需要按照**是否依赖方向翻转**，放入对应的分支即可。

扩展后的完整商业级玩家节点树如下：

Plaintext

```
Player (CharacterBody2D)                     ← [根节点] 挂载主脚本，掌控全局物理与逻辑
├── PhysicsCollision (CollisionShape2D)      ← [主物理体] 挡墙踩地（居中，不翻转）
├── GroundRayCast (RayCast2D)                ← [固定射线] 向下检测悬崖/陡坡/地面材质（不翻转）
├── Timers (Node)                            ← [定时器容器] 统一收纳 Coyote, Dash 等 Timer
│   └── CoyoteJumpTimer (Timer)
├── Effects (Node2D)                         ← [固定特效/光源] 不跟随方向翻转的视觉元素
│   ├── FeetParticles (GPUParticles2D)       ← 脚下起跳/落地粒子（设置 local_coords = false）
│   └── AmbientLight (PointLight2D)          ← 角色中心自发光/黑夜剪影照明
└── Pivot (Node2D)                           ← [翻转枢纽] 所有需要跟随左右面向的节点
    ├── AnimatedSprite2D                     ← 动画贴图（可挂载 Normal Map 法线贴图）
    ├── HandLight (PointLight2D)             ← 随手部/面向变化的偏心光源（如提灯、枪口光）
    ├── WallRayCast (RayCast2D)              ← 向前探测贴墙/攀爬的射线（随 Pivot 翻转）
    ├── Hurtbox (Area2D)                     ← 受击盒
    │   └── CollisionShape2D
    ├── Hitbox (Area2D)                      ← 攻击盒
    │   └── CollisionShape2D
    └── InteractionArea (Area2D)             ← 前方交互盒
        └── CollisionShape2D
```

### 具体机制的实现方式与落位逻辑

#### 1. 射线检测（`RayCast2D`）

- **向下检测（脚下）**：直挂 `Player` 根节点。检测下落高度或地面材质（如草地/金属脚踏声）时，射线始终垂直向下，不需要镜像。
    
- **向前检测（前方）**：挂在 `Pivot` 下。探测前方是否有可攀爬墙壁或可推动物体时，射线会自动随 `Pivot` 镜像转向左右。
    

#### 2. 水面倒影（Water Reflection）

- **主流实现（无需改节点树）**：在《空洞骑士》等商业游戏中，倒影通常由**水面 TileMap 的 Shader** 自动读取屏幕纹理（`SCREEN_TEXTURE`）镜像渲染，玩家节点内部**不需要**添加额外倒影节点。
    
- **备选方案**：若使用独立 Sprite 倒影，可在 `Pivot` 下叠加一个垂直翻转 (`scale.y = -1`) 且带有透明度 Shader 的 `Sprite2D`。
    

#### 3. 光照与黑夜剪影（2D Light & Silhouette）

- **角色自发光/暗处可见**：在 `Player` 下挂载 `PointLight2D`，搭配场景的 `DirectionalLight2D`（环境光）与 **Light Mask（光照掩码）** 即可实现。黑夜中微弱光线能照亮角色，就是依靠这个自发光节点。
    
- **局部/偏心光源**：如手提灯或枪口火光，挂在 `Pivot` 下可自动随角色面向镜像到另一侧。
    

#### 4. 起跳与特效粒子（`GPUParticles2D`）

- **常驻节点法**：挂在 `Effects` 或 `Pivot` 下均可。**最关键的操作是在属性中勾选 `Local Coords = off`**。这样粒子一旦发射，就会留在世界空间中，不会因为玩家移动或 `Pivot` 翻转而跟着扭曲。
    
- **商业级生成法（推荐）**：起跳时使用 `ParticleScene.instantiate()` 直接把粒子生成并挂载到**关卡（Level）场景**中，播放完毕自动 `queue_free()`，彻底解耦。
